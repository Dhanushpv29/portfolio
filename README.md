# Python Backend Engineer — Portfolio (template)

Bilingual (German / English) portfolio built with React, Vite, Tailwind CSS and Framer Motion.
Same layout as the data-engineering version, with Python backend / AI content.

## Edit your details
Open `src/App.jsx` and change the `PROFILE` object at the top (name, initials, email, GitHub, resume link, photo).
Work experience, education and projects live in the `translations` object (`de` and `en`).

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```
